# BraidPath 0.7.1

- **Mixed TCP and Game UDP.** `proxy-client --game-mode on` carries bulk TCP responses on native HTTP/3 streams and Game UDP as prioritized DATAGRAMs in the same per-exit session. The low-level clients select the mixed policy with `--game-mode --native-return-stream` and a TCP-capable listener.
- **Native receive backpressure.** Native TCP records wait for temporary receive credit, including reorder slots. Path readers have separate staging limits, and the DATAGRAM lane continues while native reads wait.
- **Shared application budget.** The sender meters native writes in bounded parts alongside Game traffic under the existing directional and group ceilings. These ceilings account for application admission. QUIC retransmissions are measured at the transport.
- **Game telemetry.** Path snapshots report Game DATAGRAM admission, accepted native payload and DATAGRAM wait before packet selection. The 10 ms Game deadline covers local admission through the Quinn API.

## Upgrade

Upgrade all aggregate clients and servers together. The 0.7.1 aggregate handshake requires the versioned `braidpath-policy` field. It carries a single policy for first admission, additional paths and rejoin. Existing identity files can be reused.
