# BraidPath 0.7.3

- Bulk TCP uses native HTTP/3 streams in both directions. Multipath senders account for path queues, observed delivery and stream offsets when scheduling data and recovering a stalled stream head.
- Ordinary SOCKS5 UDP uses an ordered, reliable stream per destination. Choose Game mode for deadline-sensitive UDP. Game sessions reserve DATAGRAM pacing capacity while a bulk TCP stream is active.
- Mesh clients refresh entrances after interface changes and can keep local listeners available during discovery. Clients configured with a status socket expose a local JSON snapshot via `client-status`.
- The wire policy changes to version 2. Upgrade servers first, then clients. Remove each `--ordered-udp-port PORT` argument from ordinary client launch commands. Existing identities and membership can be reused.

## 中文说明

- 大流量 TCP 的上传和下载均使用原生 HTTP/3 流。多路径调度结合排队量和实际交付速度；当流头部缺失时，可通过健康路径补发。
- 普通 SOCKS5 UDP 按目的地可靠、有序交付。游戏等延迟敏感业务使用 Game 节点，同会话下载时为 DATAGRAM 保留发送预算。
- 客户端可在等待目录发现时保留本地监听，接口变化后重新发现入口。配置状态套接字后可用 `client-status` 查询运行状态。
- 会话策略升级至版本 2。请先升级服务端，再升级客户端，并从普通客户端启动命令中删除 `--ordered-udp-port PORT`。可继续使用现有身份和成员配置。
