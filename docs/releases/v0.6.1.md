# BraidPath v0.6.1

## 改进

- TCP 首次发送同时考虑路径延迟和本地发包等待，及时使用可发送的替代路径。
- 空闲连接恢复发送能力，保留拥塞制动、丢包和速率上限约束。
- 扩展单段尾包探测，修复等待中的过期定时器和独立 FIN 确认后的重传判断。
- 区分本地未发送重试与网络丢包重传，改善路径切换和短连接响应。
- 原生 SOCKS5 UDP 使用已认证的数据报探测选择路径，支持通过 mesh 中继建立会话。
- SOCKS5 CONNECT 默认提前返回，并行发送目标请求和首批应用数据。
- Mesh 公布可用的 IPv4、IPv6 地址，按路径延迟选择入口；固定目标 TCP 转发复用 mesh 发现与租约。
- 修复节点发现请求提前关闭接收流导致的启动连接重置。

## 升级与使用

将服务端和客户端一并升级到 v0.6.1。安装包包含 Linux、macOS、Windows、FreeBSD 共 11 个平台目标，以及安装脚本和 SHA-256 校验文件。

需要等待目标连接成功、获取出口绑定地址或 SOCKS5 错误码的客户端，可使用 `--socks5-wait-for-connect`。

配置说明：[代理与 mesh](../mesh.md) · [安装与升级](../install.md)

## Changes

- Rank initial TCP transmissions using path delay and local pacing wait.
- Restore idle sending allowance within measured congestion limits.
- Extend bounded tail probes and fix expired wakeups and separate-FIN recovery.
- Distinguish unadmitted local retries from network retransmissions.
- Select native SOCKS5 UDP paths with authenticated datagram probes, including mesh relay paths.
- Pipeline SOCKS5 CONNECT requests and initial application data by default.
- Advertise available IPv4/IPv6 endpoints and select entrances by latency; integrate fixed-target TCP forwarding with mesh discovery and leases.
- Prevent startup resets caused by closing mesh discovery request streams before receiving FIN.

Upgrade servers and clients together. Use `--socks5-wait-for-connect` when the caller requires the destination connection result or exit-side bound address.
