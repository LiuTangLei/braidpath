# BraidPath 0.7.2

- Clients bound to a network interface rebuild their mesh control sockets when Linux recreates the interface. They immediately refresh the directory, renew existing relay leases, and fill available relay slots, even when the direct path is still usable.
- Mesh discovery can rebind the control sockets after a bounded run of transport failures. A peer that returns a valid directory without the selected exit, or an HTTP rejection, establishes that the control socket can reach a peer.
- `proxy-client --interface` uses the selected interface for initial and periodic mesh discovery.

## 中文说明

- Linux 重建绑定的网络接口后，客户端重建 Mesh 控制连接，立即刷新节点目录、续租并补齐中继路径。直连路径仍可用时也会执行恢复。
- 发现请求连续遇到传输故障时可重建控制连接。节点成功返回目录但暂缺指定出口，或返回 HTTP 拒绝时，客户端保留仍能连接节点的控制端点。
- `proxy-client --interface` 的启动发现和定期节点刷新均使用指定接口。
