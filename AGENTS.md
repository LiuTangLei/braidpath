# Project working agreements

- Use neutral measurement labels such as `window_a` and `window_b`, and UTC timestamps.
- Describe measured conditions. Do not infer a user's nationality or location from language, infrastructure, schedules or network behavior.
- Preserve numeric measurements, timestamp instants, failures and retries when editing report annotations.
- Keep topology, credentials, run records and result analyses in ignored `local/`. Public documentation describes methods and verified implementation status.
- Do not repeat completed workloads to obtain a better result. Keep validation bounded and relevant to the change.
